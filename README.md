**Tool:** Zenmap / Nmap

This project focuses on using **Zenmap**, the graphical user interface for Nmap, to perform and analyze network scanning activities in an authorized environment. The module explores host discovery, port scanning, service identification, and the interpretation of scan results to better understand network infrastructure and exposed services.

**Key Areas:**

* 🔍 Host discovery
* 🔌 Port scanning
* 🖥️ Service identification
* 📊 Scan result analysis
* 🛡️ Network security assessment
